Suivi des invités

Les données sont stockées dans un dépôt GitHub privé. Cette page publique ne contient aucune donnée : seul un token GitHub autorisé sur ce dépôt permet d'y accéder.

Créer un token
  1. GitHub → Settings → Developer settings → Fine-grained tokens
  2. Repository access : Only select repositories → le dépôt de données uniquement
  3. Permissions → Repository → Contents : Read and write

Le token reste dans votre navigateur et n'est envoyé qu'à api.github.com.
